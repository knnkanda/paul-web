# Learning Lab

学習アプリ専用の静的LPです。新しいアプリは `app-data.js` の `apps` 配列へ、同じ形式のオブジェクトを追加してください。

## 主要ファイル

- `index.html` — ページ構造
- `styles.css` — レスポンシブな見た目
- `app-data.js` — 掲載アプリのデータ
- `app.js` — タグ検索・キーワード検索・カード描画

## 新しいミニゲームの追加依頼

新しいアプリを追加したいときは、この形式でこのチャットに送ってください。URLだけでも構いませんが、タイトル・説明・タグがあるとすぐに掲載できます。

追加方法の案内URL：
https://github.com/knnkanda/paul-web/blob/main/README.md

```text
追加：
URL：https://example.vercel.app/
タイトル：○○ゲーム
説明：○○を学ぶゲーム
タグ：算数、ゲーム
```

このチャットのURLを公開リポジトリに直接記載することは、会話内容やアクセス範囲が意図せず共有される可能性があるため避けています。公開用の共有リンクを別途作成した場合は、そのリンクをREADMEに追加できます。

## ローカル確認

ビルド不要の静的サイトです。`index.html` をブラウザで開くか、任意の静的ファイルサーバーで確認できます。
